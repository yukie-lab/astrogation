# PHASE 3 — 論文化と公開パッケージ

> 前提: Phase 2 ゲート承認済み。入力は results/ の全カタログ・全報告書・
> 式台帳・ASSUMPTIONS。**論文中に新しい物理計算を導入しない**
> (必要が生じたら STOP — それは Phase 2 の欠落であり、論文の脚注ではない)。
> 内部ゲート 3 段: 3a アウトライン → 3b 英語原稿 → 3c 日本語版+公開物。
> 各段で人間承認を得るまで次に進まない。

## 目的

二言語(英語正本+日本語版)の論文と、公開パッケージ
(Zenodo・GitHub・Jxiv)を作る。全数値は機械注入、全主張は権威ラベル
つき、AI 関与は方法として明記する。

## 言語と文体の規則

- **英語が正本(canonical)**。日本語版は忠実訳であり、数値・主張・図は
  同一の生成物を参照する(§ 数値パイプライン)
- 文体: 物理学術誌の標準文体(PRD 級)。一人称は "we"。日本語版は
  である調
- **禁止語・禁止修辞**: "novel" "remarkable" "fascinating" "delve"
  "groundbreaking" 等の自己評価形容詞(新規性は証拠で示す。形容詞で
  示さない)/ダッシュ(— や ——)による挿入・言い換えの多用(1 節に
  1 回まで。原則としてコンマ・括弧・文の分割で書く)/箇条書きの本文
  への持ち込み(本文は散文。表は表)/"In this paper" の重複開始/
  誇張的な未来展望
- 検出可能性・SETI への言及は Phase 2 の 1 頁要約の範囲内(スケーリング
  と桁まで。装置・戦略の具体化は書かない)

## 数値パイプライン(手打ち禁止 — P1 の転記事故の制度的再発防止)

- 論文中の**すべての数値**(本文・表・図キャプション)は results/ から
  機械生成する: 表は生成 LaTeX、本文数値は \input マクロ注入
- `paper_numbers_manifest.json` を生成し、原稿に現れる全数値が
  カタログ由来であることを照合するテスト(P3-C19)を認証スイートに追加
- 日本語版は同じマクロ・同じ表生成物を参照する(翻訳は文章のみ)
- 例外(桁の丸め・単位表示の変更)は manifest に変換規則ごと記録

## 論文の骨格(3a でアウトラインとして具体化し承認を得る)

1. **Introduction**: 系譜(Alcubierre → Bobrick–Martire → Warp Factory →
   Füzfa → Le)。新規性は**私たち自身の文献的確認**として書く
   (L3+world_tube+EXT1 の系統的検索で実恒星間航路計算の不在を確認)。
   **「Le 自身が future work と明記」という表現は使用禁止**(EXT1 ①)
2. **Framework**: Le の枠組みの引用ベース要約(再導出しない)。
   三層拘束と権威ラベル制度の説明(本研究の認識論的枠組みとして)
3. **Methods**: 検証方法論 — オラクル制・式台帳・認証 C1–C18・G3 二経路・
   人間ゲート。**AI 関与の開示**: 計算・実装・起草は Claude(Fable 5)が
   人間ゲート付きプロトコルの下で実施した旨を事実として 1 段落。
   6 件の相互検証(world_tube)と (73) の再現性ギャップは Methods の
   検証実績として記載(発見候補の言葉は慎重に: 「本文と公開コードから
   独立再現できなかった」という事実の記述に留め、誤りの断定はしない)
4. **Results**: 表A(座席の値段 e^(2η))/表B(50 年等高線、M31 η=11.53・
   質量比 10⁻¹⁵)/三層時間最適と拘束レジーム交差 x*=0.54/
   減速フラッシュ(前方厳密ヌル・F ∝ e^(7η−72)・ps 級時間構造)/
   GW 静寂判別子/SI 正直レイヤー(0.1 M☉・3.1e51 W)
5. **Discussion**: 限界(厚壁 future work・[N] 定義域・スペクトル非依存・
   床 tier の裁定継続)/時間-光度平面での位置(FRB・GRB との非重複)/
   技術署名の示唆(1 頁要約の範囲)
6. **Data availability**: Zenodo DOI・GitHub・コミットハッシュ・再現手順
7. 著者: 単著(Independent Researcher, Tokyo)+ ORCID。謝辞に warpax /
   world_tube(MIT)と AI 支援の明記

## 公開パッケージ(3c)

- `paper_en.pdf` / `paper_ja.pdf`(LaTeX ソースごとリポジトリに)
- Zenodo 投入セット: 両 PDF・メタデータ(タイトル・抄録 EN/JA・
  キーワード)・ライセンス(論文 CC BY 4.0 / コードは既に MIT)
- GitHub 公開準備: README(EN/JA、再現手順・認証スイートの回し方)・
  リリースタグ `v1.0-paper`(Zenodo 連携でコード DOI)
- Jxiv 投入セット(書誌情報一式。所属は Independent Researcher)
- 図の最終版(フォント・ラベル・キャプションの二言語整合)

## このフェーズ特有の STOP

- 執筆中に数値の矛盾・カタログの誤りを発見(修正は Phase 1/2 の管轄 —
  勝手に直さず報告)
- 主張したい内容に対応する権威ラベルが存在しない(= 計算が足りない)
- 新規性声明が L5+EXT1 承認済みの言い方で書けない場面に遭遇

## 禁止(このフェーズ固有)

- 数値の手打ち(P3-C19 が機械的に検出する)
- 発見候補((73) ギャップ)を著者の誤りと断定する表現
- 査読誌・掲載先への言及(本フェーズの成果物はプレプリント+公開一式)
- Three.js シミュレータ(Phase 4 として別途指示。論文と混ぜない)
