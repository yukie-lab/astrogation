## 目的

Phase 1 の各プロファイルが**外からどう見えるか**を計算する。
光度曲線・角度パターン・距離スケーリング・GW 静寂判別子。
航路表と観測署名は同じ計算の表裏である: L(u) = −ṁ は既にファイルにある。
本フェーズの仕事はそれを**観測者の時計と視線**に写すことである。

## 物理設計の要点(実装前に理解せよ)

- 排気は外向きヌルダスト (7)。静止系角度分布は (13):
  4πn² = −ṁ − 3ma·cosϑ。飽和では 3ma(1−cosϑ) — **前方極 ϑ=0 で厳密ゼロ、
  後方極 ϑ=π で最大**。この「前方抑制」が署名の指紋の半分
- 指紋の残り半分は**機動型との結合**: 減速バーンでは推力が反転し、
  排気ローブが**進行方向=目的地側**を向く(向き履歴は
  PHASE2_FORMAT の −thrust_sign に既収録)。到着型ミッションの減速フェーズは、
  目的地の観測者が排気を正面から、ドップラー増幅込みで浴びる —
  検出可能性の主役はここになると予想される
- 有限ラピディティの写像(光行差・ドップラー・遅延時間)は
  Füzfa 2019 Sec. III の機構を流用してよい(引用して使う。再発明しない)
- スペクトルは主張しない: ボロメトリック+パラメータ化シナリオのみ
  (排気の微視的物理は CLAUDE.md §7 の禁止事項)
- GW 判別子は精密に書く: Ψ₄ 静寂は **Damour 双極子機動の上でのみ厳密**
  (v3 App I)。一般の異方性は本物の GW を放射する(Damour 1994,
  gr-qc/9412063)。よって「測光で轟音・GW で無音」は**機動の純度の検査**
  でもある。対比相手はワープ崩壊 GW バースト(L4 の ref [76])

### 2-2. 観測者系光度曲線(署名カタログ本体)
各プロファイル × 観測配置(θ_obs ∈ {0°(正面=目的地), 90°, 180°(後方=出発地)}、
D は基準距離)でフラックス史 F(t_obs) を計算。
機動型 3 種の指紋を対で提示:
- flyby: 加速バーンのみ(出発地側観測者に後方ローブ)
- 到着: 加速+減速 — **減速時に目的地側観測者へローブが向く**非対称
- 往復: 4 バーンの完全な向き履歴
バーン時間はμs〜ms(R=1km)なので、観測署名は**持続時間 μs 級の
超高輝度過渡現象**になる — この時間構造を明記すること。

### 2-3. スケーリング則と桁の表
L_peak = 1.5xλ·(c⁵/G) [R] を錨に、見かけの等級/フラックスの
距離スケーリング表(kpc / Mpc / Gpc)。x, λ, R 依存性を無次元で提示し、
SI 実例は Phase 1 の si_layer と同じ R 三点。
**観測装置の性能予測は書かない**(スケーリングと桁の議論まで。
CLAUDE.md §7)。バンドはボロメトリック基準+「仮に黒体なら」等の
パラメータ化シナリオを別欄で(仮定であることをラベルで明示)。

### 2-4. GW 静寂判別子(1 節)
双極子純度と GW の関係を定量化: 純双極子 → Ψ₄ 静寂 [R]、
多重極漏洩 → GW 放射(スケーリングのみ、係数は主張しない)。
「同位置・同時刻に測光過渡 + GW 無検出」が本モデルの反証可能な
予言であることを、ワープ崩壊 GW バースト(ref [76])と対比して記述。

### 2-5. 全行 G3
署名カタログの全行に二経路照合: 遅延時間写像は独立 2 実装(§6)、
エネルギー閉合 C15 は全プロファイルに自動適用。不一致行は載せない。
