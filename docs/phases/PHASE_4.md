# PHASE 4 — 航海(Three.js シミュレータ)

> 前提: Phase 3 クローズ済み。本フェーズの成果物は**論文の主張の一部ではない**。
> リポジトリの `simulator/` 配下に置き、README で「認証済みカタログの
> 可視化作品であり、科学的主張は論文と公開データが担う」と明記する。
> 規律は一枚だけ(§物理層)。それ以外の自由度はすべて美に使ってよい。

## 作品の定義

**一隻の正エネルギーワープシェルが M31 へ航海する、一本のシークエンス。**
幹は航海体験(艦橋視点)。艦橋には航路儀(論文表A/Bの生きた計器盤)が
埋め込まれ、クライマックスで視点が反転し、目的地の観測者が 250 万年の
暗黒の果てに受け取るピコ秒の閃光を見る。

観客が持ち帰るべき一行:
**「加速するワープ船は正面から見えない。到着だけが、閃光として届く。」**

## 構成(五幕)

1. **出発** — 実時間演出。飽和バーン点火。後方双極子ローブが燃え上がり
   (前方は厳密に暗い)、星野が前方へ光行差収束を始める。計器盤に
   m(u)・x(u)・λ(u)・η(u) が動き出す
2. **巡航** — 対数時間圧縮。η が階段を昇るにつれ星野のビーミングと
   ドップラー色偏移が深まり、宇宙が前方の輪に絞られていく。
   計器盤は表A(座席の値段)を現在の η で照らす。M31 が正面で成長する
3. **反転** — 実時間演出。推力反転の一瞬。ローブが進行方向へ向き直る。
   ここから「目的地に向かって排気を焚く」照明に変わる
4. **減速** — 対数圧縮。x(u) は減衰し続け、フロンティアが広がり続ける
   (計器盤に三層と現在の λ を表示)。残存質量が e^(−72) へ向かう
5. **到着 / 視点反転** — 船は目的地系へ滑り込む。カメラが切り替わり、
   目的地の観測者となって同じ航海を「外から」再生する: 何も見えない
   250 万年(数秒に圧縮)、そして F ∝ e^(7η−72) のピコ秒フラッシュを
   対数時間リプレイでもう一度見せる(論文 Fig. 6 の体験版)

## 物理層(規律はここだけ)

- `simulator/physics.js` を**単一真実源**とする。実装する閉形式:
  m(η) = m₀e^(−3η) / x(η) = x₀e^(−3η) / 三層 λ_tier(x)(天井は閉形式、
  g̲ は数表+域外フォールバック、床は c_cons 5 点) / 飽和パターン
  3mλ(1−cosϑ)/R / 観測者写像(δ = e^η、dt_obs/du = e^(−η)、δ⁴ 増幅)/
  フラッシュ減衰 F ∝ e^(7η−3Δη_tot)
- **スナップショット認証(P4-C20)**: results/ の代表行(M31 到着 η=12 の
  m_f・x 履歴・フラッシュピーク 1.48e4・減衰尺、プロキシマ η=1 の
  Fig.4 指紋)と physics.js の出力を相対 1e-10 で照合するテストを
  1 ファイル書く。**このテストが緑になるまで描画を書き始めないこと**
- HUD・計器盤に表示する数値はすべて physics.js の出力であること。
  演出用のダミー数字を一つでも置いてはならない

## 演出層(完全に自由 — ただし物理が仲裁する)

自由: カメラワーク / 配色 / 質感 / 音(任意) / UI 様式 / ペーシング /
星野の密度と美学 / タイポグラフィ / 幕間の文言

仲裁規則(物理 > 美):
- **前方ヌルを破らない**: 加速中の船は、前方の観測者視点で光ってはならない。
  美しくても、正面が光る絵は嘘である
- 排気ローブの向きは thrust 履歴に従う(幕 1–2 は後方、幕 3–4 は前方)
- 星野の光行差・ドップラーは η から導出する(演出の誇張は倍率一つまで、
  その倍率を README に明記)
- 輝度は**対数トーンマッピング**で設計する(フラッシュのダイナミックレンジは
  線形では表現不能)。色は芸術的選択であり物理主張ではない旨を README に一行
- 時間圧縮は対数を基本とし、実時間演出は三箇所(出発・反転・到着)のみ

## 技術制約

- Three.js(CDN)+単一 HTML を基本形とする(彼女の従来作品と同型)。
  分割する場合も `simulator/` 内で完結し、ビルド工程を要求しないこと
- 星野は InstancedMesh(既往作品の instanced mesh 哲学を踏襲)
- localStorage / sessionStorage 不使用。60fps 目標、M4 iMac 基準
- 依存はCDNの three のみ(音を入れる場合は Web Audio API 素で)
