## 1. 新 C3 の定義(v3 の荷重ノードに張る)

旧 C3(|D(x)| ≥ 4/3、v2: Eq.58,60)を廃し、v3 で Theorem 2/4 の荷重を
実際に支えている ℓ≤1 / ℓ=2 閉包の非退化性に置換する。

| ID | 内容 | v3 式 | 合格基準 | 支える定理 |
|---|---|---|---|---|
| **C3a** | cos 行の閉形式: (1/a)[h_ττ]^cos = ((ρ₁+2)x + 2A_t1(1−x)^{3/2})/(x−1) の偏導が ∂/∂ρ₁ = −x/(1−x)、∂/∂A_t1 = −2√(1−x) を返し、両者 (0,1) で非零 | (77), (79) | 恒等式 相対誤差 < 1e-12、非零性を全域グリッド+端点漸近で確認 | Thm 2(Lemma 4)、Lemma 8 |
| **C3b** | ℓ=0 呼吸モード勾配 (1/a²)∂[h_ττ]^{ℓ=0}/∂ρ₀ = −x/s² ≠ 0 on (0,1)。必要性: 判別式 Δ = 16x(x−1)(9x²+11x+4) < 0 on (0,1)(双極子単独では ℓ=0 ジャンプを閉じられない) | (80), (81) | 閉形式 < 1e-12;Δ < 0 と 9x²+11x+4 > 0 の全域確認 | Thm 2(Lemma 4) |
| **C3c** | ℓ≤1 Schur 行列式 det J₀ = (∂[h_ττ]^cos/∂A_t1)·(∂[h_τϑ]^sin/∂w₁) = −2√(1−x)·1 ≠ 0 on (0,1) | (77)(Lemma 8 証明) | 閉形式 < 1e-12 | Thm 4(Lemma 8: バーン中の Schur 消去の持続) |
