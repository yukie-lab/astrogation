# L5 — 差分声明

作成日: 2026-08-08(5 文以内)

Füzfa (PRD 99, 104081, 2019) は、裸の Kinnersley 光子ロケット(点質量)による恒星間航行の相対論的運動学——軌道・エネルギーコスト・アベレーション・ドップラー——を計算したが、乗客の居住空間も、それを支える物質の許容性も扱っていない。Le (arXiv:2606.22531) は、その Kinnersley 外部に平坦な乗客キャビティを接合した正エネルギー warpshell の存在を証明し、ステアリングの厳密なコスト法則(−ṁ ≥ 3m|a|、Tsiolkovsky 係数 3)と加速–コンパクト度フロンティアを確立したが、提示したのは理論と単一の実証バーンであり、観測署名の節は v3 で削除された。我々だけが、Le の許容性制約([R] の天井 λ < ½(1−x) と厚壁窓 x_eff < 4/5 を主拘束、[N] の g̲(x) を感度帯)をすべて課した恒星間機動の全域カタログを計算し、その副産物として各ミッションプロファイル (m(u), v(u), x(u)) の観測署名——ボロメトリック光度曲線 L(u) = −ṁ と単一後方ローブの角度パターン、および GW 静寂判別子——を世界で初めて体系的に導出する。これは Lentz–Felton (2405.19381) が「提案」にとどめた warp 放射署名の探索を、初めて許容性で拘束された定量カタログとして実行するものであり、Clough et al. (2406.02466) の Alcubierre 崩壊 GW バーストとは「光学トランジェント+GW 無音」という正反対の判別軸で対をなす。航路表と署名カタログは同一の積分の表裏であり、値段(Le)の次に料金表と時刻表(我々)を作る。
