## 1. 主結果 1 — 前方厳密ヌルと減速フラッシュ(署名の指紋)

**飽和加速中のドライブは、正面(進行方向)の観測者から厳密に見えない。**
パターン 4πn² = 3ma(1−cosϑ′) の前方零点は光行差の極不動性により観測者系でも
厳密に保たれる(C17、Fraction 検証。台帳 L43/L48)。到着(減速)バーンで
推力が反転すると、排気ローブが目的地正面を向き、δ⁴ = e^(4η) の相対論的
増幅を受けたフラッシュとして届く。

**機動型 3 種の指紋**(図 sig1、`signature_summary.csv`):

| 機動型 | 出発地観測者(θ=180°) | 目的地観測者(θ=0°) |
|---|---|---|
| flyby | 加速バースト 1 回(t≈0、de-boost e^(−4η) で減光) | **厳密ゼロ**(飽和前方ヌル) |
| 到着 | 加速バースト 1 回 | **減速フラッシュ 1 回**(t ≈ D/c 後、δ⁴ 増幅) |
| 往復 | バースト 2 回(往路加速+復路減速) | バースト 2 回(往路減速+復路加速) |

側方(θ=90°)は全バーストを部分抑制で見る(唯一「全履歴」を見る配置)。

## 2. 主結果 2 — 到着時間圧縮: μs からピコ秒へ

観測者系の時間構造は dt_obs/du = 1/δ で支配される(L45、C18)。
- 出発地側(後退): バースト持続は伸長 — R = 1 km、η ≤ 1 で **μs 級**
- **目的地正面(接近)**: e^(−η) 圧縮。η = 12 の M31 到着フラッシュは
  減衰スケール ~e^(−η)/(7λ) ≈ 5×10⁻⁶ R = **~15 ps**(図 sig3、log-t 軸)。
  減衰則は閉形式 F ∝ e^(7η−72)(δ⁴ × 質量履歴)で、立ち上がり=ピーク
- 低 η の到着(プロキシマ η ≤ 1)は目的地でも μs 級(図 sig1 右)

「持続 μs〜ps 級・ボロメトリック超高輝度・単発〜数発」という時間構造が
本モデルの観測署名の骨格である(PHASE_2.md の予想「検出可能性の主役は
減速フェーズ」をカタログ全体で定量確認)。

## 4. 主結果 3 — GW 静寂判別子(2-4)

- **純 Damour 双極子機動 ⇒ Bondi news N ≡ 0 ⇒ Ψ₄ 静寂 [R]**
  (v3 Thm 5・App H の peeling 解析: ð² が ℓ≤1 を消す。原典: Damour 1995
  gr-qc/9412063 — 加速質量と放射場の遅延波が双極子レベルで相殺)
- 多重極漏洩 c_ℓ(ℓ≥2)があると J_news = Σ W_ℓ|c_ℓ|² + O(c³) > 0
  [R・線形次数、v3 (94)]: **GW エネルギーは漏洩振幅の 2 次**、燃料節約は
  1 次(v3 の trade-off)— 係数の数値は主張しない(スケーリングのみ)
- **反証可能な予言**: 「同位置・同時刻に測光過渡 + GW 無検出」。
  対比: ワープ崩壊(Alcubierre 型封じ込め失敗)は **GW バーストが主産物**
  (Clough–Dietrich–Khan 2406.02466 = v2[76]/v3[88])。本モデルの定常機動は
  正反対の判別軸に座る
- 同時に**機動純度の検査**: 測光過渡と同時に GW が検出されれば、その機動は
  非双極子(ℓ≥2 含有)であり、最小放射則から外れている
