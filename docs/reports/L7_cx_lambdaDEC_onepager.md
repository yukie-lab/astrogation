# L7 — c(x) 厳密下界と λ_DEC の正確な主張(憲法§5 改定判断用・1頁)

作成日: 2026-08-08。出典はすべて v3(arXiv:2606.22531v3)。

## A. c(x) — フロンティアの厳密下界(Lemma 6 + App C)

**主張(厳密)**: 各 x ∈ (0, 24/25) で、マッチした Darmois 殻の worst-observer
表面 DEC マージンは放射角に一様に
  8πR Φ(x,λ) ≥ M₀(x) − A(x)λ − C_shape(x)λ² …(47)=(67)
を満たし、したがって操作的フロンティアは
  **g(x) ≥ c(x) := min{ Λ_h(x), ½δ_Q(x), (√(A²+4C_shape·M₀) − A)/(2C_shape) } > 0** …(48)
- M₀(x) = −(5s−1)(s−1)/(2s) > 0(アンカーマージン、(61))、s = √(1−x)
- Λ_h(x) := ¼(1−x)(sub-horizon 帯の上限)。全定数は閉形式: Γ(x) = max{1/x, 1/(2s³)+1/(2s)}
  (49)=(68)、解析半径 r_⋆(x)(App C)、M₂(x) (69)、δ_Q(x) (71)、A(x)・C_shape(x) (72)
- 評価値 (73): c(x) ≈ {8.5, 14, 17, 14, 2.0}×10⁻⁵ at x = {0.1, 0.2, 0.3, 0.5, 0.7}

**適用条件**: (i) 分布的薄殻(Darmois/Lanczos 接合)の per-cut 準静的マッチ。
(ii) sub-horizon 帯 λ ≤ Λ_h = ¼(1−x) に制限(f−2aR ≥ ½(1−x) を保証)。
(iii) ℓ=1 剛体並進ゲージの外で評価。(iv) 保守性は Cauchy majorant (69) 由来で
**数値 g̲ ~ 0.2 より約 3 桁小さい**(v3 自身が「lower-bound must として保守的」と明記)。

**権威**: [R](閉形式・評価可能)。ただし「実際に飛べる上限」ではなく
「これ以下なら厳密に安全」の床。

## B. λ_DEC — frozen-shape 軸方向閾値(Lemma 5)

**主張(厳密)**: 形状を凍結した剛体球殻(Rindler 内部)を Kinnersley 外部に
マッチした場合の両極 worst-observer 表面 DEC マージンは
  8πR s_±(σ−p) = 3s_± − 3 + (5/2)x ± 7λ ∓ s_±λ/(1∓λ), s_± = √(1−x∓2λ) …(42)
その最小正零点 λ_DEC(x) が閾値。静的内部推定(閉形式)は
  λ̄_DEC(x) = (6√(16−14x) − |24−35x|)/98 ≈ λ_DEC(x) …(43)=(62)
- 小 x: λ_DEC = x/3 + O(x²)、λ̄_DEC = x/4 + O(x²)、比 → 3/4 …(44)
- Sturm で証明済み: 両閾値は (0,24/25) で正・両端点でゼロ・**天井 ½(1−x) より厳密に下**、
  ただし x ≈ 0.631 で天井の 0.9931 倍まで接近。前方/後方極の交叉は x = 24/35
- λ̄_DEC の精度: x ≲ 0.84 で厳密根の 1% 以内(x→24/25 で最大 2.5%)

**適用条件と警告**: これは**剛体(shape-frozen)殻の軸上診断**であり、
実際にマッチする形状応答殻の操作的フロンティア g(x) とは**別の対象**。
両者に大域的順序はない(低 x では λ_DEC ≪ g̲;v3 App C が明示)。
**g(x) の代用・拘束としての使用は禁止**。用途は (a) 認証テストの解析的
ターゲット、(b)「加速は剛体後方極をむしろ安全化する」(Remark 2)の定量化。

## C. 憲法§5(Phase 1 主拘束)への含意 — 推奨

1. **主拘束は現行維持**: [R] 天井 λ < ½(1−x)(Λ>0 では ½(1−x−y)、(20))+
   厚壁窓 x_eff = x+2λ < 4/5。変更の必要なし
2. **c(x) の追加役割**: 「厳密安全床」として航路表の各点に併記可能([R])。
   ただし ~10⁻⁴ 台であり運用拘束にすると航路が事実上消滅する — 拘束には
   しないことを推奨。g̲(x) は現行どおり [N] 感度帯(x ∈ [0.1,0.7]、外挿禁止)
3. **λ_DEC は拘束体系に入れない**(診断・認証のみ)。§5 改定は不要
