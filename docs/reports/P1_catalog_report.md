## 3. 主結果 3(新規性の核)— フロンティア騎乗の時間最適(`timeopt_bracket.*`、騎乗 81 本)

v3 Theorem 8(ii) の構造を三層で初めて数値化した:
T = R∫₀^{Δη} dη′/tier(x₀e^(−3η′))(台帳 L38)。

**x₀ = 0.3 の三層区間**(T は R 単位。到達可能時間は floor と effective の間、
真の最適は ceiling と effective の間):

| Δη | T_floor [R(A3)] | T_eff [N] | T_ceil [R]・到達不能下限 | [N]フォールバック |
|---|---|---|---|---|
| 0.24 | 2.58e3 | 1.22 | 0.824 | — |
| 1 | 3.01e4 | 3.56 | 2.88 | η_fb = 0.366 |
| 3 | 1.13e7 | 8.58 | 7.89 | η_fb = 0.366 |
| 12 | 5.98e18 | 31.1 | 30.4 | η_fb = 0.366 |

構造的知見(拘束アーク記録より):
1. **min-time は全区間が拘束弧**(飽和騎乗 a.e.、内点弧なし)— Thm 8(ii) どおり。
   多アークは長さ縮約を破る目的関数のみ(実装せず、DoD 外)
2. **壁は動く**: x(u) は放射で単調減少し、天井 (4/5−x)/2 は**広がる**。
   [N] 実効層は x = 0.1 で数表域を出て **η_fb = ln(x₀/0.1)/3 で天井 [R] に
   フォールバック**(全プロファイルで記録。x₀=0.3: 0.366 / 0.5: 0.536 / 0.7: 0.649)
3. Δη ≳ 1 では T_eff / T_ceil → 1 に接近(フォールバック後は同じ天井を騎乗、
   差は初期 [N] 区間のみ)。**実効と天井の括りは Δη 大で自動的に締まる**
4. **床 [R(A3)] は実効の ~10³ 倍遅く、Δη とともに指数的に開く**
   (c ∝ M₀ ∼ x が放射とともに消えるため T_floor ∼ e^(3Δη))。
   これは**証明の保守性**であり自然の限界ではない(PHASE_1.md 禁止事項を遵守
   して記す)。SI では R = 1 km・Δη = 0.24 の床時間 2.58e3 R ≈ 8.6 ms —
   床でも実用上は一瞬である(殻スケールが小さいため)

## 4. 主結果 4 — 拘束レジームの交差 x* ≈ 0.54(薄殻フロンティア × 厚壁実現可能性)

**(2026-08-08 人間ゲート裁定 2 により、逆転検出の註記から独立の主結果に昇格)**

**主張**: 操作的な束縛拘束は x* で切り替わる。x < x* では [N] 薄殻 DEC
フロンティア g̲(x) が束縛し、x > x* では [R] 厚壁実現可能性 (4/5−x)/2 が
束縛する。交差点は g̲ の [N]-線形補間の下で
  0.14 − 0.25(x−0.5) = (4/5−x)/2  ⟹  **x* = 0.54、λ* = 0.13** [N-interp]
(fig1 に交差点ラベルを表示。g̲ のスキャン分解能 ~5% を相続する)。

**物理的読み**: v3 §10.1 の窓の入れ子(2/3 < 4/5 < 24/25)の帰結として、
高コンパクト度では**薄殻理想化のフロンティアが厚壁として実現できる限界を
超える**。x > x* の薄殻カタログ値は「分布的殻でのみ到達可能」であり、
有限厚の物質では実現が保証されない。Le は窓の入れ子を示したが、
**g̲ と厚壁窓の交差点の定量化は本カタログが初**である(v3 に該当計算なし)。

**運用**: 騎乗・カタログの運用値は常に min(tier, 天井) にクランプ
(`frontier.tier_operative`、主拘束の併課 — 裁定 2 で追認)。根拠は
ASSUMPTIONS **A5**(g̲ は薄殻(分布的)測定であり厚壁運用を認証しない)。
テスト `test_known_inversion_raw_effective_vs_ceiling` がこの事実をデータと
して固定(g̲ 改訂で交差が動けば検出される)。

## 7. G3 照合(1-6)— `g3_log.md`

パイプライン全 306 行(表A 9 / 表B 108 / 時間最適 81 / ミッション 108)に
二経路照合を適用。**初回実行では 14 行が許容 1e-8 を超過**したが、全て
G3 検証側の数値積分精度の問題であり恒等式の不一致ではないことを確認のうえ修正:
(i) 表A の質量 ODE ステップ数を η に比例化、(ii) [N] フォールバック
イベント着地の枝凍結 RK4(枝混在 O(h) 誤差の除去)、(iii) c 鎖の Γ の
max 枝を求積分割点に追加+長スパン区間の分解能比例化、(iv) 極小 x の
(s−1) 桁落ちを x/(1+s) 形で除去。

**最終実行(`results/g3_log.md`): 306 行すべて合格、欠番 0**。最悪相対誤差:
表A 質量 7.5e-13 / 表B 時間 3.7e-16 / 時間最適 T 8.1e-10 / x_end 2.2e-11
